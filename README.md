# НЕ СЛУЧАЙНО

Свадебный сайт Александра и Татьяны, 5 декабря 2026 года.

React + Vite, локальные фотографии, музыка и шрифты. Backend: PHP 8.1+ / PDO MySQL. Вход в кабинет /admin по паролю, персональные приглашения, индивидуальные анкеты, разрешённый +1 и приватные пожелания.

## Запуск

npm ci
npm run build
node scripts/package.mjs

Размещение PHP-версии описано в DEPLOY-BEGET.md. Секретная конфигурация создаётся отдельно и не входит в репозиторий. Не коммитить config.json, sessions, базы и персональные ответы.

## GitHub Pages

GitHub Pages раздаёт статические файлы и не запускает PHP/MySQL. Для полной работы анкет и кабинета требуется отдельное размещение backend. До настройки backend нельзя считать гостевые анкеты работающими.

Пакет не содержит настоящих анкет, паролей и ключей. Материалы сайта предоставлены владельцами для свадебного приглашения; открытая лицензия на фотографии и музыку не предоставляется.

## Публикация на GitHub Pages

Готовая статическая сборка находится в docs/. В Settings → Pages выбрать Deploy from a branch, ветку main и каталог /docs, затем Save. Ожидаемый адрес после успешной публикации: https://korewkov.github.io/ne-sluchayno-wedding/

Пересборка: node scripts/pages.mjs. В сборке настроены пути фотографий, музыки и шрифтов для /ne-sluchayno-wedding/. GitHub Pages не сохраняет анкеты и не запускает кабинет; эти функции доступны после отдельного размещения PHP/MySQL backend. Не отправлять гостям персональные ссылки до подключения backend.
