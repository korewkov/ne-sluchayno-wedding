# Бесплатное размещение сайта

Состояние: независимая версия подготовлена, но ещё не опубликована на Beget. Покупка домена не требуется. Доступность без VPN в РФ нужно проверить после размещения с реального подключения.

## 1. Бесплатный адрес и HTTPS

Возможный вариант: бесплатный поддомен DuckDNS + бесплатный хостинг Beget. Подтверждение возможности привязки и SSL на конкретном аккаунте требуется в панели.

1. Войти на https://www.duckdns.org/ и создать свободный адрес, например ne-sluchayno.duckdns.org. Если занят, выбрать другой. Сохранить доступ к аккаунту; токен никому не отправлять.
2. В Beget проверить, что используется тариф FreeHosting, а не ограниченный по времени тест платного тарифа.
3. В разделе «Домены и поддомены» добавить созданный адрес как существующий внешний домен/поддомен и привязать его к сайту. Ничего не регистрировать платно.
4. В DuckDNS указать IP сервера сайта из панели Beget (не IP своего компьютера).
5. В Beget запросить только бесплатный стандартный SSL Let's Encrypt. Если панель не позволяет выпуск на бесплатном тарифе или для этого адреса, остановиться и сообщить текст ограничения. Не оплачивать услуги.
6. Если Beget сообщает отдельный IP для SSL, обновить IP в DuckDNS. После успешной выдачи проверить HTTPS и включить в Beget редирект с HTTP на HTTPS.

Официальные инструкции:
- https://www.duckdns.org/about.jsp
- https://beget.com/ru/hosting/free
- https://beget.com/ru/kb/how-to/sites/podklyuchenie-ssl-k-sajtu

## 2. Файлы и база

Архив wedding-beget-free.zip не содержит паролей, тестовой базы или анкет. В нём public_html и private, которые нужно расположить рядом в каталоге сайта. Не загружать весь проект и node_modules.

1. В разделе MySQL создать базу на бесплатном тарифе. Запомнить имя, пользователя, пароль и сервер.
2. В phpMyAdmin выбрать эту базу и импортировать private/schema.mysql.sql. Поддержка PHP 8.1+ и PDO MySQL обязательна.
3. Через файловый менеджер Beget загрузить архив в каталог сайта и распаковать так, чтобы index.html оказался непосредственно в public_html. Папка private должна быть рядом с public_html, а не внутри.
4. Локально выполнить PowerShell-скрипт D:\wedding\standalone\scripts\configure.ps1. Он запросит HTTPS-адрес, реквизиты MySQL и новый пароль кабинета; пароли вводятся скрыто. Создаст .local/production-config.json. Пароль кабинета хранится в виде хеша.
5. Загрузить полученный файл только в private/config.json. Файл содержит пароль базы: не отправлять его в чат, не класть в public_html и не включать в общий архив.
6. У PHP должен быть доступ на создание private/sessions. Не выставлять всем файлам права 777.

При повторном переносе сохранять рабочий config.json, базу и sessions. Не заменять их тестовыми файлами. Существующие приглашения из версии ChatGPT автоматически не переносятся.

## 3. Проверка после размещения

- Главная, фотографии и музыка открываются по HTTPS без входа в ChatGPT.
- /admin показывает вход по паролю; без пароля данные гостей недоступны.
- Создать тестовое приглашение из кабинета, открыть в другом браузере. Проверить ответы каждого гостя, разрешённый +1, сохранение после перезагрузки и пожелание в кабинете. Затем удалить тестовое приглашение.
- URL /private/config.json не должен отдавать файл. Не распространять ссылку, пока это не проверено.
- Проверить с мобильного интернета в РФ без VPN, затем с домашнего интернета. Проверка с одного подключения не гарантирует доступность у всех операторов.
- Музыка пытается включаться автоматически; браузер может разрешить звук только после первого действия пользователя.

Локальные проверки уже выполнены: 12 API-сценариев и браузерные сценарии входа, создания приглашения, +1, сохранения RSVP, пожеланий, мобильной версии и выхода. Реальная MySQL на Beget и его веб-сервер пока не проверены.
